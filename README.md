# ⚡ Vite React Project

Proyek ini dikembangkan menggunakan **Vite** dan **React** untuk pengembangan frontend modern dengan performa tinggi.

## 🧩 Environment Versions

| Komponen / Package         | Versi Saat Ini | Keterangan                                                                 |
| --------------------------- | -------------- | -------------------------------------------------------------------------- |
| Node.js                     | v22.20.0       | Versi runtime JavaScript yang digunakan                                   |
| Vite                        | v5.2.11        | Build tool cepat untuk proyek frontend modern                             |
| @vitejs/plugin-react        | v4.2.1         | Plugin resmi React untuk Vite, mendukung Fast Refresh & JSX transformasi  |
